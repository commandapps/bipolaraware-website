# BipolarAware Website

Marketing site for [BipolarAware](https://bipolaraware.app) — an early-warning companion for bipolar disorder.

## Local development

```bash
npm run dev
```

Opens the static site at `http://localhost:3000`.

## Deploy

Deployed automatically via Vercel on push to `main`. Production domain: **bipolaraware.app**.

## Stack

- Static HTML/CSS/JS (no framework)
- Hosted on [Vercel](https://vercel.com)
